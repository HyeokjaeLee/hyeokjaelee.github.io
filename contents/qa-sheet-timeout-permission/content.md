QA Sheet의 실행 멈춤 문제를 해결하고 권한을 정리한 날이었다.

## QA Sheet 개선

QA Sheet가 두 번째 실행에서 멈추는 문제가 있었다.

첫 번째 실행은 잘 되는데, 같은 시트로 두 번째 실행하면 멈춰버린다.

원인을 추적해보니 LLM 제공 측의 장애였다.

첫 번째 실행에서 컨텍스트가 크게 쌓이고 두 번째 실행에서 그 컨텍스트를 다시 보내니까 LLM이 응답하지 못하는 거였다.

해결책은 실행 시간을 줄이는 거였다.

컨텍스트가 덜 쌓이도록 전체 실행 시간을 1시간에서 20분으로 축소했다.

## 노션 API 호출 제거

QA Sheet가 노션 페이지 제목을 가져오기 위해 API를 호출하고 있었다.

이 호출이 실행 흐름에 병목이었다.

모달에서 입력받은 값을 시트 제목으로 직접 사용하도록 변경했다.

API 호출이 빠지니까 실행 시작이 훨씬 빨라졌다.

## 강사 접근 권한 분리

업무 프로젝트에서 강사 역할의 접근 권한을 정리했다.

강사가 접근할 필요가 없는 페이지의 접근을 제외했다.

특정 전용 문구를 삭제하고, 진단 태그 설정 링크를 조건부로 숨겼다.

Alpha 배포를 완료했다.

## 마무리

QA Sheet 타임아웃은 LLM 제공측 장애가 원인이었지만, 실행 시간 단축으로 우회할 수 있었다.

API 호출 제거도 작지만 효과적인 최적화였다.
