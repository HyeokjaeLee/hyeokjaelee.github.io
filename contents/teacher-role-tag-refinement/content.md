오늘은 한동안 붙잡고 있던 권한 관련 이슈를 정리했다.

teacher 역할로 로그인한 사용자가 보면 안 되는 메뉴가 몇 군데 있었다.

접근 권한이 걸려 있지 않아 URL만 알면 들어갈 수 있었고, 관리자 전용 문구도 그대로 노출되고 있었다.

진단 태그 설정 링크도 마찬가지였다.

권한이 없는 역할에게도 보이고 있었고, 클릭하면 설정 화면까지 열려버렸다.

## 권한 제외와 문구 정리

teacher 역할에서 접근할 수 있는 범위를 한 번에 훑었다.

접근 권한을 역할 단위로 묶어서 제외하고, 매니저 전용 문구는 아예 지웠다.

문구를 그대로 두면 헷갈리니까 누구에게 보이는 문구인지 역할 기준으로 다시 나눴다.

## 진단 태그 설정 링크 조건부 숨김

진단 태그 설정 링크는 권한이 있는 역할에만 보이게 했다.

조건부 렌더링이라 링크 자체가 그려지지 않고, 권한이 바뀌면 자동으로 노출 여부가 바뀐다.

이렇게 하면 나중에 역할이 늘어나도 링크를 일일이 숨길 필요가 없다.

## QA 도구 쪽 잡일

같은 날 QA 자동화 도구도 손을 봤다.

노션 페이지 제목을 가져오려고 API를 한 번 더 호출하고 있었는데, 모달에서 입력한 값을 그대로 시트 제목으로 쓰도록 바꿨다.

호출 한 번이 줄었고, 사용자가 입력한 값이 그대로 제목이 되니까 더 직관적이다.

그리고 두 번째 실행이 멈추는 문제가 있었다.

원인은 LLM 제공 측 장애였고, 전체 실행 시간을 1시간에서 20분으로 줄여서 타임아웃 여유를 확보했다.

## Alpha 배포

정리한 내용을 Alpha에 반영했다.

teacher 역할로 로그인했을 때 더 이상 관리자 화면이 보이지 않는다.

진단 태그 설정 링크도 권한 있는 역할에게만 나타난다.

간단해 보이지만, 권한은 한 구간 놓치면 사고로 이어지는 부분이라 꼼꼼히 확인한 날이었다.
