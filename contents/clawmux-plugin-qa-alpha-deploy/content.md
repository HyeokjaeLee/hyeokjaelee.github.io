하루에 두 가지 큰 작업을 동시에 진행한 날이었다.

ClawMux 플러그인 개발과 QA 에이전트 Alpha 환경 배포.

둘 다 다른 프로젝트인데 타이밍이 겹쳤다.

## ClawMux 플러그인

ClawMux는 Context-Gateway와 라우터를 통합하는 플러그인이다.

LLM 기반 요청 분류기를 구현했다.

요청이 들어오면 LLM이 복잡도를 판단해서 적절한 provider와 모델로 라우팅한다.

가벼운 요청은 저렴한 모델로, 복잡한 요청은 비싼 모델로 보낸다.

이전까지는 키워드 기반으로 분류했는데, 키워드만으로는 요청 복잡도를 정확히 판단하기 어려웠다.

## QA 에이전트 Alpha 배포

QA 에이전트를 Alpha 환경에 배포했다.

Graviton2 인스턴스로 마이그레이션하면서 ARM64 호환성을 확인했다.

배포 직후 큐 동시 실행 버그가 발견돼서 급하게 수정했다.

### 크래시 3중 방어

qa-sheet에서 EISDIR과 EEXIST 에러로 크래시가 발생했다.

디렉토리를 파일로 열려고 하거나(EISDIR), 이미 존재하는 파일을 다시 만들려고(EEXIST) 할 때 발생하는 에러다.

이런 에러가 발생하면 전체 실행이 죽어버린다.

3중 방어를 구현했다.

에러 발생 시 재시도, 경로 정규화, 디렉토리 자동 생성.

어느 지점에서 에러가 나도 전체 실행이 멈추지 않도록 방어했다.

### passed 비율 개선

첫 실행 결과를 분석했다.

passed 비율이 55%에서 76%로 올랐다.

앞선 작업들(DAG 스케줄링, 재시도 로직, Inspector 분리)이 효과를 낸 거다.

## qa-sheet UX 개선

qa-sheet 모달 UX를 개선했다.

기존에는 URL을 직접 텍스트로 입력해야 했다.

모달 팝업으로 바꿔서 시트를 선택할 수 있게 했다.

실수로 잘못된 URL을 입력하는 경우가 크게 줄었다.

## 마무리

passed 비율 76%는 의미 있는 수치다.

스모크 테스트 시작 시 50%였으니까 한 달 사이에 26% 포인트가 올랐다.

ClawMux도 LLM 분류기가 들어가니까 라우팅 품질이 눈에 띄게 좋아졌다.
