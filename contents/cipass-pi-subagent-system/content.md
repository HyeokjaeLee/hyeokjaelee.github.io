ci-pass 스킬을 확장하고 Pi 에이전트 서브에이전트 시스템을 구축한 날이었다.

## ci-pass 스키ㅇ 트리거 확장

ci-pass 스킬이 한국어 자연어 요청에도 반응하도록 트리거를 확장했다.

기존에는 영어 명령어만 인식했는데, "CI 통과시켜줘" 같은 한국어 요청도 처리하도록 바꿨다.

## Pi 서브에이전트 시스템

Pi 에이전트에 서브에이전트 시스템을 구축했다.

역할별로 에이전트를 분리했다.

탐색 에이전트는 코드를 읽고 구조를 파악한다.

수정 에이전트는 코드를 변경한다.

검증 에이전트는 변경된 코드가 정상 동작하는지 테스트한다.

리뷰 에이전트는 코드 품질을 검토한다.

### 병렬 비동기 패턴

서브에이전트들이 병렬로 동작하도록 비동기 작업 패턴을 확립했다.

탐색과 수정은 순차적으로, 검증과 리뷰는 병렬로 실행한다.

코드 탐색용 MCP 도구도 연동했다.

## 마무리

역할 분리를 하니까 각 에이전트 프롬프트가 단순해진다.

하나의 에이전트가 모든 걸 하려고 하면 프롬프트가 길어지고 품질이 떨어진다.
